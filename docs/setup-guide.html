Set up Daily Companion

One private live store. Choose Notion (recommended) or GitHub with optional Obsidian.

1. Start in ChatGPT

Read the current System/setup.md from https://github.com/yilinqiao/daily-companion-with-chatgpt/blob/main/System/setup.md and guide me through exactly its onboarding questions, one at a time. Do not invent questions; stop if the current setup text or version cannot be verified. Immutable commit SHA verification may wait until after the questionnaire. Do not write personal data or activate tasks until full release verification and my respective summary approval.

Confirm name, location, work hours, the full daily planning window (e.g. 07:00–21:00, including work), language, communication style, then storage. If only commit SHA verification is pending, complete the conversation-only questionnaire; finish release verification before connector preflight or installation.

2A. Notion (recommended)

No Notion account yet? Sign up with Google. Connect Notion in ChatGPT, grant the necessary read/write and schema/view access to your private suite, and approve setup. The assistant creates or verifies System, Daily Briefing & Memory and Action Ledger data sources and views. Morning and provisional Evening auto-save; approve revisions to the same page.

2B. Private GitHub

Use this template → Create a new repository → Private, never a public fork. Connect your private repository with read/write access. Approve setup and interactive daily saves. Obsidian is optional.

3. Approve and verify setup, then tasks

Calendar and Gmail are optional. Approve each connected source and test access. Verify setup before separately approving Morning, Evening, Extra and Update Watch tasks. Extra is silent on other dates, and Watch is silent on no change; platform notifications may still occur.

Check Notify when complete and Settings > Notifications, plus device permissions. Confirm actual first runs, not just enabled state.

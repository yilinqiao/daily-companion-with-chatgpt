An open, private-first starter kit

Set up your Daily Companion

Make a personal AI companion with ChatGPT and your own private GitHub vault. Optional Obsidian, Gmail and Calendar connections can be added once you approve them.

Public template → Your private repository

First: protect your privacy

Use this template, not Fork. GitHub public forks remain public. Daily Memory and a personalized profile can contain sensitive details, so your daily vault must be a new Private repository.

Only generic instructions and empty configuration belong in the public source. Your notes, personal schedule and action items belong in your private copy.

Step 1

Make your private copy

  1. In the public Daily Companion repository, click Use this template, then Create a new repository.
  2. Choose your account and a repository name. Select Private.
  3. Confirm the new repository has System/setup.md, System/profile.md and System/workflows/.
Step 2

Connect ChatGPT

  1. Connect GitHub to ChatGPT, allowing access to your newly created private repository.
  2. Start a conversation with the following instruction and replace the placeholder with your actual owner/repo.
Read System/setup.md from GitHub repository <OWNER>/<YOUR_PRIVATE_REPO> and start Daily Companion setup. Ask exactly one question per turn. Do not change files or create scheduled tasks before I approve the summary.

You will answer one question at a time about location, time zone, schedule, style, optional data sources and preferred run times.

Step 3

Approve and verify

  1. Approve only the confirmed setup summary and data-source permissions.
  2. Let ChatGPT personalize System/profile.md and initialize the ledger in your private repository.
  3. Ask ChatGPT to verify the saved file and commit. A displayed summary is not proof of persistence.
  4. If your account supports scheduled tasks with the needed connector access, verify Morning, Evening and Extra tasks; otherwise use interactive runs.
Optional

Use Obsidian on your devices

Clone your private repository on desktop, or use a compatible Git-based sync client on mobile. Open it as an Obsidian vault. The Kanban and Slurp community plugins provide an action board and saved-page workflow.

Consult Resources/Obsidian GitHub GitSync Setup.md for platform-specific steps. Confirm that mobile sync actually works before relying on it.

What to expect

Morning Companion

Reads approved available sources and the Action Ledger to present a daily briefing. It does not silently write notes during a scheduled run.

Evening Companion

Helps review today and tomorrow, captures reliable same-day explorations when visible, drafts a Daily Memory and asks you to approve before saving.

Can ChatGPT always see other chats?

No. Cross-chat context may be incomplete or unavailable. The system uses reliable timestamps or your confirmation and should acknowledge missing coverage.

Can I use it without Gmail or Calendar?

Yes. Both are optional. Your private GitHub vault is the storage requirement in this architecture.

Final security check

Verify that your personal repository says Private, that the source repo remains generic, and that you've never added credentials or other secrets to Git. Keep a separate backup of important notes.

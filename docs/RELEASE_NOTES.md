# Initial public template release

These are historical notes from the unversioned public packaging. Current versioned releases and migration notes are maintained in [CHANGELOG.md](../CHANGELOG.md); existing users start at [System/upgrade.md](../System/upgrade.md).

This is a public-source, privacy-first packaging of the **clean** Daily Companion Starter. The canonical state design uses an unconfigured profile, Action Ledger with Closed and standing precedents, read-only scheduled runs and approval-based interactive persistence. Evening may summarize same-day discussions only when timestamp metadata or user confirmation supports attribution.

There are no live user Daily notes, real account credentials or active personal task records in the published source. New users should generate **private** repositories with GitHub's template feature. Changes to this public template do **not** automatically update users' separate repositories.

**Status: experimental.** The static checks do not prove behavioral parity with every previously used live version, or reliable operation for every ChatGPT plan, mobile sync implementation, connector permission set and Scheduled Task environment. Perform the fresh-account smoke tests in RELEASE_REVIEW.md before broad promotion.
